# Contributing

Contributions are welcome if they improve the clarity, usefulness, or practical depth of the framework.

## Contribution Principles

Please keep contributions aligned with the core philosophy:

- No manipulative sales tactics
- No pressure-based scripts
- No fake urgency
- No insulting current vendors or teams
- No exaggerated promises
- No generic advice without context

This project is about consultative selling, executive communication, and long-term trust.

## Good Contributions

Good contributions may include:

- Better discovery questions
- Stronger objection-handling examples
- Audit templates
- Follow-up examples
- Decision frameworks
- Anonymized case studies
- Better diagrams
- Practical checklists

## Case Study Rules

If you submit a case study:

- Remove client names unless you have permission
- Remove private performance data unless it is public or approved
- Focus on the sales process and decision-making
- Do not expose confidential strategy

## Style Guide

Write clearly.

Use short paragraphs.

Prefer practical examples over theory.

Avoid buzzwords unless they add clarity.

The best contribution should make a reader think:

> I can use this in a real client conversation tomorrow.
